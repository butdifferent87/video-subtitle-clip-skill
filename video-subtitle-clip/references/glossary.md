# 한국어 마술 용어 표기표

번역을 시작할 때 읽고, 번역자(서브에이전트)에게 나눠 맡길 때는 이 표를 브리프에 그대로 붙인다.
같은 기법이 영상마다·배치마다 다르게 적히면 시청자는 다른 기법으로 오해한다. 그리고 한국 마술계에서 실제로 부르는 이름과 다르면 검색해도 안 나온다.

## 🔴 오너가 정한 표기 — 틀리면 고친다

| 원어 | 쓸 표기 | 쓰지 않을 표기 | 이유 |
|---|---|---|---|
| Elmsley count | **엠슬리 카운트** | 엘름슬리 카운트 | 한국 마술계의 관용 표기. 철자대로 음차하면 「엘름슬리」가 나와서 번역자가 자꾸 그렇게 쓴다(2026-11-20, 렉처 4편에 42곳 → 일괄 교정). |
| Alex Elmsley (인명) | **알렉스 엠슬리** | 알렉스 엘름슬리 | 기법 이름과 같은 표기로 맞춘다. |
| bottom deal | **바텀 딜** | 보텀 딜 | 오너 지정 표기(2026-11-21, Nuova Magia 6곳 → 일괄 교정). 기법 맥락의 bottom card 등도 「바텀」. |

새 교정을 받으면 이 표에 한 줄 추가하고, **아래 grep 정규식에도 그 틀린 표기를 `|` 로 덧붙인다**(원어 · 쓸 표기 · 틀린 표기 · 날짜와 이유).

## 인물·책·원리

후안 타마리스(Juan Tamariz), 니모니카(Mnemonica), 피트 하틀링(Pit Hartling), 다이 버넌(Dai Vernon), 아스카니오(Ascanio), 레나트 그린(Lennart Green), 사이 스테빈스(Si Stebbins), 길브레스 원리(Gilbreath principle).

마술 제목은 영어 그대로 두고 「 」로 감싼다(예: 「Wild Kings」). 기법은 우리말로 풀지 않고 음차한다 — 처음 나올 때만 괄호 설명 가능: 바텀 딜(맨 아래 카드를 돌리는 기술).

## 끝내기 전 확인

산출물 `.srt` 에서 「쓰지 않을 표기」 열의 단어를 검색해 0건인지 본다:

```bash
grep -cE "엘름슬리|보텀" OUT.srt     # 0 이어야 한다 (표에 줄이 늘면 "|틀린표기" 처럼 덧붙인다)
```

0 이 아니면 `build_from_groups.py` 에 넣기 전의 묶음 파일(`groups.tsv`)에서 일괄 치환하고 다시 빌드한다. 산출물 `.srt` 를 직접 고쳐도 되지만, 그러면 스크래치패드의 `ko.srt`·묶음 파일과 어긋나 나중에 다시 빌드할 때 틀린 표기가 되살아난다:

```bash
sed -i 's/엘름슬리/엠슬리/g; s/보텀/바텀/g' groups.tsv     # 표의 줄마다 하나씩
```
