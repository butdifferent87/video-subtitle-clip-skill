# 타임 마커 — 마술별 「연출」「해법」 시작점

마술 영상은 연출(시연)과 해법(해설)이 떨어져 있어서, 사용자는 원하는 마술의 해설로 바로 건너뛰고 싶어 한다. 자막 작업을 하면 받아쓰기 원문을 다 읽게 되니 마커는 거의 공짜로 따라온다 — 그래서 요청이 없어도 매번 만든다.

## 1. markers.tsv 쓰기

받아쓰기(또는 번역 배치)를 읽으며 쓴다. 한 줄 = `시각<TAB>마술 이름<TAB>연출|해법|기타`.

```
00:00:26	인트로 (리스본 공연)	기타
00:05:52	Ring off Rope	연출
00:41:10	Ring off Rope	해법
```

- **연출** = 그 마술 시연이 시작되는 큐(관객 앞 공연이든 카메라 앞 시연이든). **해법** = 설명이 시작되는 큐. **기타** = 인트로·잡담·이론 토크·크레딧.
- 시각은 짐작하지 말고 **그 대사 큐의 시작 시각**을 쓴다(SKILL.md 2-b 와 같은 원칙). 시연 직전 소개 멘트("Here's a trick called…")가 있으면 그 큐.
- 마술 이름은 영상에서 부르는 **원어 이름만** 쓴다(해설·촬영 슬레이트에서 부르는 이름). 한국어 번역을 괄호로 덧붙이지 않는다 — 사용자가 원어 이름으로 마술을 찾는다. `기타` 항목도 원어로(`Intro`, `Interview`, `Outtakes`). 같은 마술의 연출·해법은 **이름 글자까지 똑같이** 써야 목록에서 짝이 맞는다.
  - Good: `Ring off Rope / 연출`, `Ring off Rope / 해법`
  - Bad: `Ring off Rope / 연출`, `Ring Off The Rope / 해법` → 스크립트가 「해법 없음」을 찍는다
- 공연 파트의 마술들이 해설 파트에서 따로 나오는 구조가 흔하다. 한 마술에 연출이 두 번(공연 + 해설 중 재시연)이면 둘 다 적는다.
- 큐가 수천 개라 번역을 서브에이전트 배치로 나눴다면, 배치마다 마커 후보를 받아 마지막에 합치고 이름을 통일한다. 청크 경계에서는 앞 마술의 연속인지 확인한다.

## 2. 세 파일 만들기

```bash
python3 scripts/make_markers.py markers.tsv "OUT_DIR/<원본이름>"                                 # B: 렉처 전체
python3 scripts/make_markers.py markers.tsv "SCRATCH/<클립이름>" --offset -763 --duration 129   # A: 클립 (원본 기준 시각이면 -구간시작)
```

→ `<이름>.pbf`(팟플레이어 책갈피), `<이름>_markers.txt`(목록), `<이름>.ffmeta`(mp4 챕터).

(윈도우에서는 SKILL.md 윈도우 표대로 `python -I -X utf8 scripts/make_markers.py ...`)

- **A (구간 클립)**: `burn.sh`(또는 직접 렌더)로 자막을 구운 **뒤**, 재인코딩 없이 챕터만 심는다(수 초). `burn.sh` 는 모르는 옵션에서 멈추므로 렌더 명령에 끼워 넣지 않는다.
  ```bash
  ffmpeg -i OUT_sub.tmp.mp4 -i SCRATCH/<클립이름>.ffmeta -map 0 -map_chapters 1 -c copy -movflags +faststart OUT_sub.mp4
  ffprobe -v error -show_chapters OUT_sub.mp4      # 챕터가 찍히는지 확인
  ```
  `.ffmeta`·`.pbf` 는 스크래치패드에 두고 `_markers.txt` 만 산출물 폴더로.
- **B (렉처 전체)**: `.srt`·`.pbf`·`_markers.txt` 를 **원본 영상과 같은 폴더**에 바로 쓴다(사용자 지정, 2026-11-20). 팟플레이어는 영상과 같은 폴더·같은 이름의 `.srt`·`.pbf` 만 자동으로 읽기 때문이다. 같은 이름 파일이 이미 있으면 덮어쓰기 전에 묻는다.

⚠️ 첫 챕터가 0초가 아니면 ffmpeg 가 mp4 챕터 시각을 앞으로 당겨 버린다(실측: 2초 챕터가 0초로). 스크립트가 0초에 「시작」 챕터를 자동으로 깔아서 막는다.

## 3. 확인

- 스크립트가 「해법 없음」을 찍으면: 이름 오타면 고치고, 해설이 다른 디스크에 있거나 시연만 있는 거면 그대로 둔다(목록 머리에 표시된다).
- `_markers.txt` 를 대화창에 올려 사용자가 훑게 한다 — 마술 이름은 받아쓰기에서 자주 깨진다.
- B: 팟플레이어에서 영상을 열고 책갈피 목록(우클릭 → 재생 → 책갈피)에 마커가 뜨는지 본다. `.pbf` 형식(`[Bookmark]` / `번호=밀리초*제목*`, UTF-16)은 팟플레이어가 저장하는 형식을 따랐지만 아직 실물 확인 전이다 — 처음 쓴 사용자가 확인해 주면 이 줄을 「실측 확인」으로 바꾼다.
